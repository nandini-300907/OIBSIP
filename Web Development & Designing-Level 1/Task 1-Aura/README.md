# Aura – Mind & Body Wellness Landing Page

## Project Overview

Aura is a clean and responsive wellness landing page designed to promote physical and mental wellbeing. The website focuses on encouraging simple, mindful habits that help users maintain balance in their everyday lives.

## Objective

The objective of this project is to build a visually polished static landing page using HTML5 and CSS3 while demonstrating fundamental web development and responsive design skills.

## Features

- Sticky navigation bar with multiple navigation links
- Hero section with headline, description, and call-to-action button
- Wellness section featuring Mind, Body, and Balance
- About Aura section
- Contact section with email interaction
- Responsive layout for desktop, tablet, and mobile screens
- Consistent wellness-inspired colour palette
- Clean and readable typography
- Footer with navigation links and project information
- Smooth scrolling between sections

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Responsive Media Queries

No JavaScript was required for this project.

## Steps Performed
1. Planned the structure of the Aura wellness landing page.
2. Created the HTML structure using semantic sections.
3. Added a sticky navigation bar with navigation links.
4. Designed the hero section with a clear headline and call-to-action.
5. Added wellness, about, and contact sections.
6. Created a footer with navigation links.
7. Styled the complete page using CSS3.
8. Applied Flexbox and CSS Grid for layout.
9. Added responsive media queries for smaller screen sizes.
10. Tested the website in a web browser to verify the layout and navigation.

## Design Inspiration
The design was developed after reviewing landing-page design concepts and layouts for inspiration. The final design was created independently for Aura and was not copied from any existing website.

## Outcome
The completed Aura landing page provides a simple, clean, and responsive interface focused on physical and mental wellness. The website works across different screen sizes and demonstrates the fundamental HTML and CSS requirements of the task.
